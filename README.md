# Project Title

Imposter Game

## Description

Imposter Game is a "pass the device" fun game you run in a web browser. You pick the amount of people playing (3–10), then choose one or more word categories (famous cities, technology, food, or clothing), and you can choose whether or not to give the imposter a clue. The app secretly assigns one random imposter and gives everyone else the same secret word from your selected categories. Players take turns looking at their role or word in private, hands it off to the next person. This is a simple game requiring no accounts and/or server. After the round is over you can choose to replay with the same settings or edit them.

Note: Developed without AI
